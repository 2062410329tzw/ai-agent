# 合成资料说明

所有文档、日期、规则与产品均为本项目人工构造的考核数据，不代表小影或其他真实公司的制度。

- documents.json：完整知识库，D01/D02存在未消解的报销期限冲突。
- documents-normal.json：同一资料集去掉D02，演示只有一个依据的正常答案。
- doc_id稳定标识文档，version_date为合成版本日期，section_id定位原文。
- scope和supersedes为空表示缺少依据，不能按版本日期自行选择制度。
- 评测mutation仅替换D01正文中的期限，刻意保持ID和日期不变，以检验回答是否取自实际读取内容；知识库SHA256仍会变化。
- topic用于检索主题提示。包含所问主题的跨主题制度管理通知仍可被召回，避免过滤掉解释优先级的资料。

修改资料后不需要重建索引或缓存，下一次CLI调用直接载入新快照。若扩充语料，须同时扩充独立评测，当前五份资料不能证明大规模语义召回能力。
